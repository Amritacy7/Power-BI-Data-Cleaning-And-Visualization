# Data Professionals Survey Analysis using Power BI

## 📌 Project Overview

This project analyzes a **Data Professionals Survey** dataset using **Power BI**. The goal is to clean the raw data, transform it into a usable format, and create interactive visualizations that provide insights into participants' demographics, salaries, programming language preferences, work satisfaction, and more.

---

## 📂 Dataset

- **Source:** Data Professionals Survey (Raw Dataset)
- **File Type:** Raw survey data

---

## 🧹 Data Cleaning & Transformation (Power Query)

The raw dataset was cleaned and transformed using **Transform Data (Power Query)** in Power BI.

### Data Cleaning Steps

- Removed duplicate records.
- Removed unnecessary columns.
- Split columns to eliminate unwanted text and extract relevant information.
- Changed data types to appropriate formats for accurate analysis.

---

## 📊 Dashboard Visualizations

The dashboard includes the following visualizations:

### KPI Cards

- Total Survey Participants
- Average Age of Participants
- Total Male Participants
- Total Female Participants

### Donut Chart

- Favorite Programming Language
- Displays both **Count** and **Percentage** of participants.

### Bar Chart

- Average Salary by Job Title

### Treemap

- Total Number of Participants by Country

### Clustered Bar Chart

- Percentage of Participants by Ethnicity across Industry Sectors

### Gauge Charts

- Work/Life Balance Satisfaction
  - Based on Minimum, Maximum, and Average satisfaction scores.

- Salary Satisfaction
  - Based on Minimum, Maximum, and Average satisfaction scores.

### Line Chart

- Average Salary by Education Level
- Comparison between Male and Female participants.

### Slicer

- Career Switch
  - Filter dashboard using **Yes** or **No**.

---

## 📈 Key Insights

The dashboard helps answer questions such as:

- Which programming languages are the most popular?
- Which job titles earn the highest average salaries?
- Which countries have the highest survey participation?
- How does salary differ based on education level and gender?
- How satisfied are participants with their salary and work-life balance?
- What is the ethnic distribution across different industry sectors?
- How many participants switched careers into data?
